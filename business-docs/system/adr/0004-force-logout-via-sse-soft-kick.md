# 密码变更后旧 Token 立即硬失效：密码版本号 + 实时事件软踢

旧 Token 在自然过期前始终有效（Token 黑名单是空壳实现），两次登录签发的 Token 并存可用，已被实际验证。决定在系统用户上引入密码版本号：口令每次修改或重置时递增，新签发 Token 的声明携带该版本号，认证中间件比对不一致即返回 401，使该用户全部旧 Token 立即失效；停用与删除校验并入同一次用户查询。实时事件 `forceLogout` 仅承担在线页签立即登出的体验职责，不是安全边界；安全边界是版本号比对。

考虑过落地 Token 黑名单：需要按 Token 粒度维护撤销状态，与登出语义纠缠，复杂度更高，弃。也考虑过单会话互踢（登录版本号）：会使网页端与接口调试工具无法同时使用，不符合实际使用方式，弃。多会话并存是明确保留的能力。
