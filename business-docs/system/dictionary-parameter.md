# 字典与系统参数规则

## 数据字典

- **SYS-CFG-001** 字典条目以字典类型和标签组合保持唯一；同一类型可通过父子关系组织层级选项。
- **SYS-CFG-002** 字典树筛选命中子节点时保留必要祖先，命中父节点时保留相关后代，确保结果仍可理解为树。
- **SYS-CFG-003** 字典状态只允许启用或停用；变更父节点状态会递归同步其后代状态。
- **SYS-CFG-004** 有子节点的字典条目不能删除。已被业务记录快照引用的历史语义由来源模块负责保留。
- **SYS-CFG-005** 字典提供选项和值含义，不定义医疗挂号、处方、ERP 单据等业务状态的允许流转。

## 系统参数

- **SYS-CFG-010** 参数键使用大写字母、数字和下划线组成的稳定标识；不能以展示名称代替程序读取键。
- **SYS-CFG-011** 参数类型只允许字符串、数字、布尔和 JSON，保存时按声明类型验证值。
- **SYS-CFG-012** 公开参数值接口只返回明确标记可公开的参数，并转换为其声明类型；未公开参数不能通过公共读取入口取得。
- **SYS-CFG-013** 参数删除采用软删除。修改程序依赖的参数键、默认值或范围时，必须同步所有读取方和来源领域文档。

## 安全边界

系统参数不用于保存密码、Token、私钥或数据库连接串等秘密。必须保存的敏感运行配置应使用专门的密钥管理方案，不得因参数支持 JSON 就将其公开。
