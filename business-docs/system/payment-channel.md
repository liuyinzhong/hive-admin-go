# 支付渠道规则

## 配置维度

- **SYS-PAY-001** 支付渠道类型只允许微信支付或支付宝，代码值分别为 wechat 和 alipay。
- **SYS-PAY-002** 运行环境只允许 development、testing、staging 和 production，环境之间的配置互不替代。
- **SYS-PAY-003** 渠道名称和应用 ID 必填；差异化配置为空或合法 JSON，不能保存无效 JSON 文本。
- **SYS-PAY-004** 状态只允许启用或停用；删除采用软删除。

## 默认渠道

- **SYS-PAY-010** 同一渠道类型和运行环境下最多一条未删除记录标记为默认。
- **SYS-PAY-011** 新建、编辑或单独设为默认时，在同一事务内清除同维度其它默认标记，再保存目标记录。
- **SYS-PAY-012** 取消默认只影响目标记录，不自动选择替代渠道；业务调用方必须处理当前维度没有默认渠道的情况。

## 权限与安全

- **SYS-PAY-020** 列表、创建、详情、更新、删除、状态和默认标记由支付渠道权限控制；默认标记当前复用更新权限。
- **SYS-PAY-021** 支付渠道模块当前只维护接入配置，不创建支付订单、回调结果或退款记录。
- **SYS-PAY-022** 应用 ID、差异化 JSON、回调地址及其中可能出现的密钥或证书信息均按敏感配置处理，不得写入业务文档、提交记录或普通日志。
- **SYS-PAY-023** 当前响应 DTO会返回完整差异化配置，通用操作日志也可能记录请求体。这是现状风险，不应被当作安全设计；后续应在不破坏调用方的前提下设计脱敏和密钥托管。
