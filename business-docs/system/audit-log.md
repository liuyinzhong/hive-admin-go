# 审计日志规则

## 日志类型

- **SYS-AUD-001** 操作日志记录受审计中间件覆盖的业务请求，包括操作者、接口、请求结果、耗时和客户端信息；它不替代领域状态日志。
- **SYS-AUD-002** 登录日志独立记录登录、退出及其结果，便于按认证事件查询。
- **SYS-AUD-003** 操作结果按 HTTP 状态判断，HTTP 状态大于等于 400 记为失败；业务接口应保持 HTTP 与业务结果语义一致。

## 查询

- **SYS-AUD-010** 操作日志和登录日志提供分页、筛选、详情查询和异步导出，不提供页面修改或删除动作。
- **SYS-AUD-011** 日期范围和状态筛选必须以服务端查询为准，前端不得在已分页结果上假装完成全量筛选。
- **SYS-AUD-012** 操作日志和登录日志列表、详情都按日志 `user_id` 应用当前角色数据范围；匿名失败事件或其它空用户归属日志只允许全部数据范围用户查看。
- **SYS-AUD-013** 登录日志异步导出使用与列表相同的用户名、事件类型、状态、IP、日期和排序条件；任务创建接口受 `system:loginLog:export` 权限保护，Worker 执行时按任务创建用户重新解析当前角色数据范围，并按日志 `user_id` 过滤。

## 敏感信息

- **SYS-AUD-020** 日志不得长期保存密码、Token、私钥、支付密钥、证书口令或完整敏感业务数据；新增接口进入审计范围时必须检查请求和响应脱敏。
- **SYS-AUD-021** 当前通用审计可能记录请求体和响应体。涉及支付渠道等敏感配置的接口存在泄露风险，后续修改应优先建立字段级脱敏，并评估已有日志的治理方案。
