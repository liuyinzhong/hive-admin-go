# 系统消息与下载领域词汇

用于统一 Hive 菜单消息、实时事件和异步文件导出中的核心语言。

## 消息语言

**菜单消息**：发给一个用户并归属于一个页面菜单的持久化未读记录。
_Avoid_: 站内信、右上角通知、短信、邮件

**未读汇总**：将一个用户的未读菜单消息按菜单聚合得到的数量集合。
_Avoid_: 消息列表、通知内容

**菜单角标**：根据未读汇总显示在目标菜单及其上级菜单上的数量提示。
_Avoid_: 通知中心红点、任务进度

**实时事件**：通过当前在线连接发送给一个用户的瞬时状态变化提示，本身不承担持久化和最终一致性职责。
_Avoid_: 菜单消息、审计日志

## 下载语言

**下载任务**：一个用户按指定筛选和排序发起、由后台异步生成文件的工作记录。
_Avoid_: 同步下载、业务任务、导出文件

**来源模块**：创建下载任务并定义导出业务范围的功能模块。
_Avoid_: 下载中心、任务类型

**导出器**：负责解释某类下载任务条件并生成对应文件内容的后台能力。
_Avoid_: 下载接口、页面导出按钮

**活动任务**：仍处于等待或生成状态、尚未成功或失败终结的下载任务。
_Avoid_: 全部历史任务、已完成文件

**导出文件**：下载任务成功后生成、在保留期内仅供任务创建者下载的文件结果。
_Avoid_: 下载任务、上传文件

**文件保留期**：导出文件成功生成后允许下载的时限。
_Avoid_: 下载任务记录保留期、业务数据有效期

**任务记录保留期**：导出文件清除后，下载任务元数据继续保留供查询的时限。
_Avoid_: 文件保留期、日志保留期
