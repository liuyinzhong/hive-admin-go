# 系统管理领域词汇

用于统一 Hive 登录授权、系统基础配置、文件、审计、外部页面、支付渠道、菜单消息和异步下载中的核心语言。具体运行规则见 [系统管理业务手册](./README.md)。

## 访问控制语言

**系统用户**：可以登录 Hive 并被授予角色、部门和菜单权限的账号。
_Avoid_：医生档案、企业联系人、患者

**系统内置用户**：承担平台管理职责、在普通用户管理中受特殊保护的账号。
_Avoid_：普通管理员、自定义角色

**角色**：把菜单和按钮权限集合授予一组系统用户的访问控制载体。
_Avoid_：职位、部门、医生职称

**角色用户**：被授予某个角色的系统用户；同一份授权关系既可在角色管理中按角色维度维护，也可在用户表单中按用户维度维护，两侧操作的是同一份数据。
_Avoid_：角色成员、成员、用户组、角色拥有者

**部门**：组织系统用户的层级节点，可用于人员归属和领导关系。
_Avoid_：临床科室、企业主体

**菜单**：动态路由树中的目录、页面、内嵌页、链接或按钮权限节点。
_Avoid_：业务模块本身、浏览器书签

**原子权限码**：绑定到按钮节点并由后端受保护路由显式校验的唯一动作标识。
_Avoid_：角色名、菜单路径、页面标题

**数据范围**：角色对已获准调用接口的用户进一步限定其可见、可写、可统计和可导出业务记录的范围。
_Avoid_：接口权限、菜单可见性、前端筛选条件

**记录归属人**：通过创建人、办理人、执行人等明确用户字段承接通用角色数据范围的系统用户。
_Avoid_：数据库操作账号、最后查看人、任意关联用户

**个人签名**：系统用户在个人中心维护的签名图片资料；可随时修改或清空，只作为流程签署时生成签名快照的来源，本身不构成审批证据。
_Avoid_：签名快照（工作流的不可变证据）、电子签章

**领域归属**：由流程参与者、当前排班医生、处方开具人与审核人等业务关系决定的访问边界。
_Avoid_：角色部门范围、页面按钮权限

**密码哈希**：系统用户口令经 bcrypt 单向散列后的唯一存储形态，自含盐与成本因子，不可逆推原文。
_Avoid_：加密后的密码、密码密文、明文密码

**密码强度**：系统对口令的硬性要求：长度 8 至 72，且至少包含小写字母、大写字母、数字、特殊字符四类字符中的两类。
_Avoid_：复杂度校验、强度条（仅展示计分不拦截）

**修改密码**：系统用户验证旧口令后自助更换新口令的动作。
_Avoid_：重置密码、找回密码

**重置密码**：管理员在用户管理中为目标系统用户直接设置新口令的动作，不经过旧口令验证。
_Avoid_：修改密码、找回密码（自助找回路径）

**全局主数据**：全系统共同引用、不按创建人切分，由原子权限和业务状态控制的配置或档案。
_Avoid_：所有带 creatorId 的数据、公共匿名数据

**用户权限明细**：一个系统用户经其全部关联角色当前配置形成的菜单授权明细视图，按配置事实展示并标注停用状态；与登录后动态菜单的生效口径（SYS-ACL-004，仅有效角色×启用菜单）是两个不同边界。
_Avoid_：生效权限、动态菜单副本、用户权限码集合（那是按权限码去重的集合）

**用户权限明细查询**：按用户维度一次聚合返回该用户全部角色及各自菜单授权明细的只读查询；由后端聚合接口提供并执行与用户详情一致的数据范围边界，前端不逐角色拼装。
_Avoid_：逐角色详情拼装、前端权限推导

**权限明细行**：用户权限明细的最小展示单元，表示一个角色对一个菜单节点（目录、页面、内嵌页、链接或按钮）的授权；明细按菜单树层级嵌套展示，目录作为表达上下级关系的层级节点出现；同一权限被多个角色授予时在各角色分组内分别出现，不做去重。
_Avoid_：权限去重集合、扁平路径串

**权限摘要**：用户管理列表权限明细单元格展示的授权计数视图：角色数、各角色授权节点数之和（多角色重复授权不去重，与用户权限明细各角色分组计数一致）、个人额外授权节点数与个人禁止节点数四项。
_Avoid_：生效权限统计（那是三元合并去重口径）、角色列（只展示角色名称的旧形态）

**权限明细入口**：用户管理列表权限明细单元格（展示权限摘要）提供的用户权限明细查看入口；仅对持有用户权限明细查询权限的用户渲染为可点击链接，其余用户保持静态文本展示，后端接口仍独立校验权限。
_Avoid_：公开点击入口、仅前端隐藏

**个人权限**：直接作用于单个系统用户、独立于角色的菜单授权调整，由个人额外授权和个人禁止两个集合组成；只影响功能权限（菜单与按钮），不改变数据范围。
_Avoid_：用户角色、直授权限、个人数据范围

**个人额外授权**：授予某个系统用户的、其角色集合之外的菜单节点集合；按提交集合完整替换，只加不减不影响角色已有授权。
_Avoid_：个人角色、复制角色、增量补丁

**个人禁止**：显式收回某个系统用户经角色获得的菜单节点集合；合并时绝对优先于角色授权和个人额外授权；按提交集合完整替换。
_Avoid_：黑名单、负权限、角色修改

**用户生效权限**：用户全部有效角色的菜单授权与个人额外授权的并集，减去个人禁止，且仅启用菜单进入生效口径；系统内置超级用户不受个人禁止影响。
_Avoid_：角色权限、动态菜单、数据范围

**菜单受众**：一个菜单节点被哪些角色收录、被哪些用户额外授权、对哪些用户禁止的只读聚合视图。
_Avoid_：菜单详情、权限明细、授权入口

## 配置与资源语言

**数据字典**：以类型和层级条目维护、供业务字段选择的可配置值集合。
_Avoid_：系统参数、硬编码状态机

**系统参数**：通过稳定参数键保存、由程序读取的字符串、数字、布尔或 JSON 配置值。
_Avoid_：字典条目、环境密钥

**上传文件**：用户上传并由系统保存元数据和私有存储位置的文件资源。
_Avoid_：异步导出文件、打印结果

**操作日志**：记录已认证业务请求及其结果的审计记录。
_Avoid_：登录日志、业务状态日志

**登录日志**：记录登录、退出及其成败信息的认证审计记录。
_Avoid_：操作日志、在线会话

**外部页面**：以特殊菜单记录维护、通过公开解析接口展示的外部内容入口。
_Avoid_：普通动态菜单、内嵌页面

**支付渠道**：按支付平台和运行环境保存的一组支付接入配置。
_Avoid_：支付订单、收款记录、退款单

## 消息语言

**菜单消息**：发给一个用户并归属于一个页面菜单的持久化未读记录。
_Avoid_: 站内信、短信、邮件

**通知中心**：顶栏铃铛弹层内逐条展示当前用户最近菜单消息的通知列表，是菜单消息的逐条消费入口；与菜单角标消费同一份数据、已读状态互通；只保留最近若干条，不是全量消息归档页。
_Avoid_: 菜单角标（按菜单聚合的入口）、消息归档页、站内信

**未读汇总**：将一个用户的未读菜单消息按菜单聚合得到的数量集合。
_Avoid_: 消息列表、通知内容

**菜单角标**：根据未读汇总显示在目标菜单及其上级菜单上的数量提示。
_Avoid_: 通知中心红点、任务进度

**实时事件**：通过当前在线连接发送给一个用户的瞬时状态变化提示，本身不承担持久化和最终一致性职责。
_Avoid_: 菜单消息、审计日志

**密码版本号**：口令的世代计数，口令每次修改或重置时递增；旧世代的会话凭证随版本比对失败而全部失效。
_Avoid_: Token 黑名单、会话版本、登录互踢

**登录有效期**：新签发会话凭证自签发时刻起可用的小时数，由系统参数配置；仅在签发时消费，不追溯已签发凭证。
_Avoid_: 会话超时、密码版本号

**滑块挑战**：登录前由服务端签发、随登录请求一次性消费的短时效凭证；只能通过完成滑块交互获得，不可重放。
_Avoid_: 验证码（图形/短信）、captcha 布尔值（纯前端标记）

**失败触发**：某用户名在滚动窗口内的登录失败数达到阈值后，其登录请求必须携带有效滑块挑战的规则；阈值以下不校验。
_Avoid_: 账号锁定、硬锁定

**签发限流**：对滑块挑战签发接口按来源 IP 施加的频率上限，用于阻止脚本无限领票。
_Avoid_: 登录限流、账号锁定

**令牌撤销**：登出时将该枚会话凭证的唯一标识写入黑名单使其立即失效的动作；只撤销当前凭证，不影响同一用户的其它会话。
_Avoid_: 强制退出（面向在线页签的事件）、全端下线、密码版本号递增

**强制退出**：密码变更后要求目标用户的全部在线页签立即清理会话并返回登录页的动作；其旧世代的会话凭证同时被服务端判定失效。
_Avoid_: 登出（用户主动操作）、踢下线、登录互踢（单会话）

**整组已读**：进入叶子菜单时把该菜单下全部未读消息一次性标记已读的动作；由侧边菜单选择或通知中心点击消息项跳转触发，是进入菜单的唯一已读口径。
_Avoid_: 逐条已读、全量已读

**逐条已读**：在通知中心通过消息项上的已读按钮把单条菜单消息标记已读的动作；不跳转、不影响同菜单其它消息，是系统内唯一的单条已读路径。
_Avoid_: 整组已读、全量已读、点击消息项（点击触发的是整组已读）

**全量已读**：把当前用户全部菜单消息一次性标记已读的动作，由通知中心的全部已读按钮触发，生效后所有菜单角标归零。
_Avoid_: 整组已读、逐条已读、清空（消息不可删除）

## 下载语言

**下载任务**：一个用户按指定筛选和排序发起、由后台异步生成文件的工作记录。
_Avoid_: 同步下载、业务任务、导出文件

**来源模块**：创建下载任务并定义导出业务范围的功能模块。
_Avoid_: 下载中心、任务类型

**导出器**：负责解释某类下载任务条件并生成对应文件内容的后台能力。
_Avoid_: 下载接口、页面导出按钮

**活动任务**：仍处于等待或生成状态、尚未成功或失败终结的下载任务。
_Avoid_: 全部历史任务、已完成文件

**导出文件**：下载任务成功后生成、在保留期内仅供任务创建者下载的文件结果。
_Avoid_: 下载任务、上传文件

**文件保留期**：导出文件成功生成后允许下载的时限。
_Avoid_: 下载任务记录保留期、业务数据有效期

**任务记录保留期**：导出文件清除后，下载任务元数据继续保留供查询的时限。
_Avoid_: 文件保留期、日志保留期
