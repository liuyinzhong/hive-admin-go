# 表单领域词汇

本文件只统一表单领域的业务语言。运行规则见 [表单业务手册](./README.md)。

**表单 Schema**：一份可复用的结构化表单定义，包含唯一标识、布局、字段树、校验规则和启停状态。
_Avoid_：某次用户提交的数据、流程定义、页面源码

**Schema 标识**：供其它模块稳定引用表单 Schema 的业务键；创建后用于识别同一份表单定义。
_Avoid_：数据库主键、表单名称

**字段树**：由顶层字段和容器字段的子字段组成的结构；同一 Schema 内所有字段名共享一个命名空间。
_Avoid_：数据库列、任意 JSON

**组件类型**：字段在设计器和运行表单中采用的受支持控件类型。
_Avoid_：前端任意组件路径

**字段校验**：服务端依据字段定义对提交值执行的必填、类型、长度、范围或格式约束。
_Avoid_：只在浏览器生效的提示

**布局**：表单内容按单列、双列或三列组织的整体展示方式。
_Avoid_：流程画布、字段组件类型

**流程绑定**：工作流定义引用某个表单 Schema 作为发起和审批数据结构的关系。
_Avoid_：流程实例提交、表单预览

**运行时表单值**：流程发起或审批过程中，按照已发布定义快照保存的用户业务数据。
_Avoid_：Schema JSON、设计器配置
