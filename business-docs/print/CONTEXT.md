# 打印领域词汇

本文件只统一打印领域语言。运行规则见 [打印业务手册](./README.md)。

**单据类型**：决定可用字段注册表和打印数据来源的业务单据类别。
_Avoid_：模板名称、打印文档 ID

**打印模板**：某一单据类型的可编辑版式定义，包含页面、区块和元素配置；版式采用 worm-vue3-print 的 TemplateData 协议，后端只做边界校验并原样存储。
_Avoid_：实际单据、浏览器打印结果

**TemplateData 版式**：worm-vue3-print 定义的模板 JSON 结构（纸张、方向、页边距、页眉/页脚/首页叠加层/内容区元素，坐标单位 mm）；模板元信息（名称、单据类型、状态、版本）不在这个 JSON 里，由宿主记录维护。
_Avoid_：自研 PrintLayout 五区块结构（已废弃）

**默认版式**：后端按单据类型注册的只读初始布局。设计器中由用户主动"加载默认布局"时通过接口获取并填入画布，加载本身不落库，保存草稿后才成为草稿版式。
_Avoid_：创建模板时写入的版式、前端内置的布局数据

**草稿版式**：模板当前可编辑内容，保存后仍不能直接作为正式业务打印依据。
_Avoid_：已发布版式

**已发布版式**：模板最近一次成功发布时固化的正式内容，是业务打印使用的权威版式。
_Avoid_：设计器中的未保存或未发布修改

**字段注册表**：特定单据类型允许模板引用的主数据字段、明细字段和展示类型集合；明细集合根（如 `items`，DataType=list）作为表格数据源注册项。
_Avoid_：任意数据库字段、前端临时变量

**字段边界校验**：后端对 TemplateData 中全部 `{表达式}` 文本的静态扫描：点分路径必须命中字段注册表，标识符必须命中渲染函数/系统变量白名单；发布时另加元素数量、ID 唯一性和明细表格数据源校验。
_Avoid_：渲染级排版校验（由设计器与浏览器预览负责）

**打印元素**：放置在页面区块中的文本、长文本、数据表格、条形码、二维码、图片、线条、形状、HTML 或页码等可打印对象。
_Avoid_：业务字段注册项、单据明细

**模板预览**：使用草稿版式和指定或示例数据生成的视觉验证结果。
_Avoid_：正式打印

**正式打印**：使用已发布版式和真实业务单据数据生成打印页面的动作。
_Avoid_：设计器预览、文件下载
