# 打印文档规则

## 数据来源

- **PRINT-DOC-001** 每种单据类型通过后端注册的数据提供器读取真实业务单据；打印模块不自行复制或维护来源单据。
- **PRINT-DOC-002** 首期正式数据来源为采购入库单，字段含义和可见范围必须同时遵守 [采购入库规则](../erp/purchase-inbound.md)。
- **PRINT-DOC-003** 字段注册表描述模板可引用的主字段和明细字段。新增来源字段时，必须同步注册表、数据提供器、前端设计器和本文。

## 预览与正式打印

- **PRINT-DOC-010** 设计器可以使用指定采购入库单或示例数据预览草稿版式；预览成功不表示模板已发布。
- **PRINT-DOC-011** 正式业务打印只能使用已发布版式；没有已发布版式时必须明确失败，不能回退使用草稿。
- **PRINT-DOC-012** 打印数据实时取自来源单据，打印模块不固化一份独立业务快照；来源数据变化会反映到后续打印结果。
- **PRINT-DOC-013** 正式采购入库单打印需要独立打印权限，不能仅凭模板查看或编辑权限获得。

## 边界

- 浏览器打印或另存 PDF 属于客户端输出行为，后端当前不保存打印次数、打印人或生成文件。
- 打印模板只决定展示，不改变采购入库单状态、库存或财务数据。
