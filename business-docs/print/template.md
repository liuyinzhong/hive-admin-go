# 打印模板规则

## 模板生命周期

- **PRINT-TPL-001** 当前每种单据类型最多维护一份未删除模板；首期只注册采购入库单类型。
- **PRINT-TPL-002** 模板状态为草稿或已发布。创建和任意版式更新后，当前状态变为草稿。
- **PRINT-TPL-003** 系统只保存“当前草稿”和“最近发布”两份内容，不提供历次发布历史。
- **PRINT-TPL-004** 发布把通过严格校验的草稿复制为已发布版式；发布后继续编辑草稿不影响正式打印，直至再次发布。
- **PRINT-TPL-005** 更新和发布必须携带正确行版本；版本过期时返回并发冲突，不能覆盖其他人的修改。
- **PRINT-TPL-006** 删除模板会删除当前模板记录；执行前应确认该单据类型可以暂时没有正式打印模板。

## 页面与版式

- **PRINT-TPL-010** 页面规格允许 worm-vue3-print 全集（A4/A3/A5/Letter/Legal/自定义），方向只允许纵向或横向，页边距各边取值范围为 0 至 40mm；坐标单位固定 mm。
- **PRINT-TPL-011** 草稿保存执行边界校验：TemplateData JSON 合法、页面结构合法、模板中全部 `{表达式}` 的点分路径命中字段注册表、其余标识符命中渲染函数/系统变量白名单；允许设计过程中的暂不完整内容。发布在草稿基础上从严：必须至少一个元素、元素 ID 唯一、明细表格数据源必须是注册的明细集合根。
- **PRINT-TPL-012** 渲染级排版检查（元素尺寸、越界、分页效果）由设计器画布和浏览器预览负责，后端不复刻渲染管线。
- **PRINT-TPL-013** 字段元素和表格单元格表达式只能引用该单据类型注册的字段；明细表格数据源只能是注册的明细集合根（如 `items`）。
- **PRINT-TPL-014** 模板不能通过任意字段路径读取未注册数据，字段注册表是模板可见数据边界；后端通过表达式静态扫描保证该边界。
- **PRINT-TPL-015** 版式允许两种形态：单页 TemplateData，或 1.3.0 起的多页面 wrapper（`{ version, pages }`，各页版式不同、整份绑定同一份数据）；wrapper 按页执行 PRINT-TPL-010/011 的边界校验，且至少包含一页、各页纸张尺寸（含方向）必须一致——渲染端整份一次出图，共用一份纸型。发布时的「至少一个元素」按整份统计，元素 ID 唯一性按页判定（各页独立渲染）。

## 预览与权限

- **PRINT-TPL-020** 模板预览使用当前草稿，供设计人员检查版式；它不改变发布状态。
- **PRINT-TPL-021** 打印模板和字段元数据是全局配置，不按模板创建人应用角色部门数据范围；拥有对应原子权限的用户维护同一套模板。
- **PRINT-TPL-022** 打印模板列表、元数据、创建、详情、更新、发布、删除和预览分别受对应打印模板权限保护；修改路由时必须同步权限按钮配置。

## 当前限制

- 没有发布历史、版本回退或多模板选择能力。
- 服务端 PDF 输出未接入；当前打印输出由浏览器端 PrintHtmlPreview 渲染管线完成，后续接入 worm-vue3-print-render 后可提供服务端 PDF/截图。
- 元素内表达式的语义合法性（如聚合函数用在明细行）不做后端校验，错误表达式在渲染时保留原文。
- 删除是高影响动作，前端必须二次确认并在成功后重新查询当前模板。
