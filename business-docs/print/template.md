# 打印模板规则

## 模板生命周期

- **PRINT-TPL-001** 当前每种单据类型最多维护一份未删除模板；首期只注册采购入库单类型。
- **PRINT-TPL-002** 模板状态为草稿或已发布。创建和任意版式更新后，当前状态变为草稿。
- **PRINT-TPL-003** 系统只保存“当前草稿”和“最近发布”两份内容，不提供历次发布历史。
- **PRINT-TPL-004** 发布把通过严格校验的草稿复制为已发布版式；发布后继续编辑草稿不影响正式打印，直至再次发布。
- **PRINT-TPL-005** 更新和发布必须携带正确行版本；版本过期时返回并发冲突，不能覆盖其他人的修改。
- **PRINT-TPL-006** 删除模板会删除当前模板记录；执行前应确认该单据类型可以暂时没有正式打印模板。

## 页面与版式

- **PRINT-TPL-010** 当前页面规格只允许 A4，方向只允许纵向或横向，页边距各边取值范围为 0 至 40。
- **PRINT-TPL-011** 草稿保存执行基础结构校验，允许设计过程中的暂不完整内容；发布执行完整校验。
- **PRINT-TPL-012** 发布时必须存在有效区块和元素，元素 ID 必须唯一，坐标与尺寸必须在页面可打印范围内。
- **PRINT-TPL-013** 字段元素只能引用该单据类型注册的字段；明细表格及其列也只能引用注册的明细集合和字段。
- **PRINT-TPL-014** 模板不能通过任意字段路径读取未注册数据，字段注册表是模板可见数据边界。

## 预览与权限

- **PRINT-TPL-020** 模板预览使用当前草稿，供设计人员检查版式；它不改变发布状态。
- **PRINT-TPL-021** 模板列表、元数据、创建、详情、更新、发布、删除和预览分别受对应打印模板权限保护；修改路由时必须同步权限按钮配置。
- **PRINT-TPL-022** 打印模板和字段元数据是全局配置，不按模板创建人应用角色部门数据范围；拥有对应原子权限的用户维护同一套模板。

## 当前限制

- 没有发布历史、版本回退或多模板选择能力。
- 页面规格和元素类型以注册表当前支持集合为准。
- 删除是高影响动作，前端必须二次确认并在成功后重新查询当前模板。
