# 工作流领域词汇

本文件只统一工作流领域语言。运行规则见 [工作流业务手册](./README.md)。

**流程定义**：可反复发起流程的设计模板，包含流程图、表单绑定、字段权限、状态和版本。
_Avoid_：某一次流程实例

**流程画布**：由开始、审批、条件、抄送和结束等节点及连线组成的流程结构。
_Avoid_：表单 Schema、运行时轨迹

**流程发布**：校验定义完整性并生成可供新实例使用版本的动作。
_Avoid_：保存草稿、启动流程

**流程实例**：用户依据已发布定义发起的一次具体业务流程，持有定义、流程和表单快照。
_Avoid_：流程定义、待办任务

**审批任务**：流程运行到审批节点时，分配给办理人的待处理工作。
_Avoid_：抄送、流程实例

**会签**：审批节点要求全部指定办理人完成同意后才能通过的方式。
_Avoid_：任一人审批、加签

**或签**：审批节点任一指定办理人同意即可通过的方式。
_Avoid_：会签、转办

**转办**：当前办理人把自己的待办责任转交给另一名有效用户。
_Avoid_：加签、抄送

**加签**：在当前审批组中增加额外办理人的动作。
_Avoid_：转办、流程定义修改

**退回**：将运行中的流程回到已经经过的审批节点并重新生成后续办理路径。
_Avoid_：拒绝、撤销

**抄送**：向接收人提供只读知会记录，不赋予审批权。
_Avoid_：审批任务、消息通知

**字段权限**：流程节点对表单字段施加隐藏、只读或可编辑约束的规则。
_Avoid_：接口权限码、菜单权限

**状态同步事件**：业务模块在审批节点属性中配置的稳定语义标识（如 review、close），流程引擎在节点通过时按此事件把关联业务对象的状态更新为对应值；曾称“节点业务键”，底层属性键仍为 nodeBusinessKey。
_Avoid_：结束后动作、审批动作、消息通知

**结束后动作**：结束节点声明的流程通过后落地行为；第一版仅支持创建需求，随画布保存（属性键 createStoryOnFinish），与流程定义业务归属类型互斥。
_Avoid_：状态同步事件、业务归属类型、流程回调

**流程落地需求**：纯审批流程通过后按表单同名字段映射创建的规划中需求；创建人为流程发起人，需求变更记录与业务流程关联留痕来源审批实例。
_Avoid_：需求评审流程、手工创建需求、流程副本
