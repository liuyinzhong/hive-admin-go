# 流程定义规则

## 生命周期

- **WF-DEF-001** 流程定义标识由后端通过公共编码流水 `base_code_sequence` 的 `WORKFLOW_DEFINITION` 域自动生成，格式为 `WF` + 6 位补零流水号（如 `WF000001`），全局唯一且递增，不接受前端传入；创建后只读回显，不可修改。新建定义版本为 0、状态为草稿。
- **WF-DEF-002** 定义状态为草稿、已发布或已停用。只有已发布定义允许发起新实例。
- **WF-DEF-003** 修改流程图、画布配置或绑定表单的运行结构后，定义退回草稿；必须重新发布。
- **WF-DEF-004** 发布成功时版本递增。已有实例保存定义、流程和表单快照，不跟随后续修改。
- **WF-DEF-005** 删除采用软删除；历史实例继续使用自身快照，不因定义删除而丢失运行记录。

## 发布校验

- **WF-DEF-010** 流程图必须且只能有一个开始节点，并至少有一个结束节点。
- **WF-DEF-011** 节点类型只允许开始、审批、条件、抄送和结束；普通节点必须有且只能有一条有效出口，结束节点不能有出口。
- **WF-DEF-012** 审批节点办理人来源只允许用户、直属领导或角色，审批方式只允许或签或会签。
- **WF-DEF-013** 条件节点至少两条出口，每条优先级为唯一正整数，并且必须且只能有一条默认出口。
- **WF-DEF-014** 条件表达式使用受支持的结构化规则和运算符，不能提交任意执行脚本。
- **WF-DEF-015** 绑定表单时，发布要求 Schema 处于启用状态且存在可提交值字段；无有效表单结构时不得发布。
- **WF-DEF-016** 节点字段权限只允许隐藏、只读和可编辑，且只能引用绑定 Schema 中的字段。字段权限可配置于发起节点和审批节点：发起节点未配置字段默认可编辑，审批节点默认只读。
- **WF-DEF-017** 流程定义必须声明业务类型（BUSINESS_TYPE 字典值）才能发布；业务类型须已在后端业务类型注册表登记（0需求/10任务/20缺陷/30版本）。
- **WF-DEF-018** 节点挂载的自动化动作快照必须完整：动作类型受支持、目标字段在该业务类型的可写字段白名单内、目标值非空，否则发布拒绝。
- **WF-DEF-019** 手动发起流程（startType=0）不绑定业务对象，不能挂载修改字段值动作；挂载了自动化动作的定义必须为被动触发流程（startType=1）。

## 启动类型与默认流程

- **WF-DEF-030** 启动类型是流程定义的必选属性：0 手动发起流程（默认，出现在"发起申请"入口，纯流程、不绑定业务对象）；1 被动触发流程（不出现在申请入口，由业务对象发起，必须携带业务对象）。
- **WF-DEF-031** 发起校验双向拦截：被动触发流程从通用发起接口不带业务对象发起时拒绝；手动发起流程携带业务对象绑定时拒绝。带业务对象的发起只允许被动触发流程。
- **WF-DEF-032** 默认流程标志仅被动触发流程可设，在定义新增/编辑表单中勾选维护，不提供独立设置入口；同业务类型下唯一，勾选保存时同事务自动顶掉该类型原默认。业务对象创建后的自动发起按"启动类型=被动触发 + 默认标志 + 业务类型 + 已发布"精确匹配，不再按最新发布猜测。
- **WF-DEF-033** 定义改为手动发起流程时默认标志自动清空；业务类型变化时默认标志随表单联动清空，也可在勾选状态下直接改挂到新业务类型（顶掉新类型原默认）。
- **WF-DEF-034** 被动触发流程不能关联表单：其唯一发起路径是业务对象自动发起，没有发起人填表单环节，表单校验必然以空变量执行（含必填字段时发起静默失败）。绑定接口拒绝、定义改为被动触发时自动解绑表单、发布校验兜底拦截。审批过程中如需收集信息，待后续支持独立的审批表单能力后再放开。
- **WF-DEF-035** 条件分支依赖表单字段作为流程变量，被动触发流程不关联表单时变量恒为空，条件节点恒走默认分支；被动触发流程不应配置条件分支。

## 自动化动作

- **WF-DEF-040** 自动化动作是全局主数据，在独立菜单按业务类型分组维护；动作库软删除或停用不影响已挂载到画布的快照，已发布/运行中的流程继续按快照执行。
- **WF-DEF-041** 版本1 仅支持修改字段值动作（`update_field`）：配置目标字段（限该业务类型可写字段白名单，当前仅状态字段）与目标值（限对应字典合法值）；动作参数以 JSON 存储，为插入记录等后续动作类型预留。
- **WF-DEF-042** 设计器挂载动作时按流程定义的业务类型过滤可选项（仅启用的动作），选中即把动作配置快照写入节点属性（`automations` 数组，可多个、可排序）；同一节点同一动作只能挂载一次。
- **WF-DEF-043** 修改挂载属于画布变更，定义退回草稿并需重新发布；已有实例保存画布快照，按发起时配置执行。

## 与表单联动

- **WF-DEF-020** 表单 Schema 的字段 JSON、布局或状态发生结构性变化时，引用定义被退回草稿；重新发布前必须核对条件和字段权限。
- **WF-DEF-021** 定义发布只验证当时结构；运行实例以发布快照为准，不能读取最新草稿替换实例结构。

## 数据边界

流程定义、画布和表单绑定是全局配置，不按定义创建人应用角色部门数据范围；各动作仍需独立原子权限。流程实例、任务和抄送不继承定义创建人的范围，而按运行时参与者规则控制。
